دعوة زفاف سعد وفاطمة
=====================

المحتويات: index.html و style.css و script.js ومجلد assets للصورة والأغنية.

المعاينة: افتح index.html في متصفح حديث. يلزم اتصال إنترنت لتحميل خطوط Google Fonts؛ وتعمل الصفحة أيضًا بخطوط بديلة عند عدم الاتصال.

النشر على Vercel: سجّل الدخول إلى vercel.com، اختر Add New > Project، ثم ارفع هذا المجلد كمشروع ثابت أو ارفع محتوياته إلى GitHub واربط المستودع بـ Vercel. لا يحتاج المشروع إلى build command؛ اجعل Output Directory هو .

ملاحظات مهمة قبل النشر النهائي:
- صورة الخلفية عولجت آليًا لإخفاء الشريط الأسود. قد تظهر منطقة الترميم ناعمة قليلًا؛ يُفضّل مراجعتها أو استخدام نسخة أصلية بدون الشريط إن توفرت قبل النشر النهائي.
- الأغنية المرفقة هي الملف الذي أرسلته، وتبدأ بعد ضغط «افتح دعوتنا». تأكد من امتلاك حق استخدامها ومشاركتها.
- الموعد مضبوط على الجمعة 4 ديسمبر 2026 من 5 إلى 11 مساءً بتوقيت القاهرة. زر التقويم ينزّل ملف ICS مع تنبيه قبل يوم؛ ظهور التنبيه يعتمد على تطبيق التقويم وإعدادات جهاز الضيف.
- رابط الخريطة متروك لإضافته لاحقًا.
- نموذج التهاني واجهته موجودة، لكنه غير مربوط بخادم؛ لن تُرسل الرسائل أو تُحفظ مركزيًا قبل ربط خدمة مثل Formspree أو Firebase/Supabase.
- برنامج الحفل المعروض نص تمهيدي قابل للتعديل وليس جدولًا تفصيليًا نهائيًا.
